## 使用规则

## 必须实测的判断

以下问题在本章只能提出观察需求，不能由教学计数给出结论：

- 任何真实延迟、吞吐、goodput 或 SLO 达成率的数值结论。
- 教学拍数分布与真实负载分布的对应关系（不存在这种对应）。
- 开环与闭环哪种更接近某具体生产流量（需要真实流量到达过程统计）。
- 分位算法（插值、sketch）在大样本下的误差取舍。

真实结论必须沿用第 00 章的测量合同：固定请求集合与生成工作量，记录观察者和完成事件，保留原始事件、失败与环境信息，再限定结论适用范围。

## 确定性教学模型假设

任务组 1 的指标层只用于形成可复核的因果推导：

- 事件底座复用第 07 章 `buildTerminationTrace`（含到达/准入/排队/执行/带原因终态），指标层不另设事件族。
- 固定工作量 `K-a`—`K-f`（6 请求、6 块池、无界排队、prefill 优先），注入两处终止：`K-b` 在 t5 被客户端取消（生成中）、`K-e` 在 t5 超时（首执行期限 t3，排队中）。
- 指标定义为事件对差值：排队 = 准入拍 − 到达拍；首 token = 首个输出事件拍 − 到达拍；间隔 = 相邻输出事件拍之差；端到端 = 终态拍 − 到达拍。教学单位是拍；定义可迁移到真实时间戳，数值不可迁移。
- 分位数用最近邻秩（第 ⌈p·N⌉ 个排序值）并在正文登记；样本量小时 p99 退化为最大值的事实如实呈现。
- 闭环对照：串行客户端（下一请求到达 = 上一请求终态拍 + 1），注入不随环式迁移；开环与闭环共用同一服务与请求集合。
- goodput：有效完成 = 终态原因为 eos/length 的请求；被取消、超时、断开、失败者按原因列入排除清单。
- 均值-尾部反例使用登记的教学分布（A=[1,1,1,1,5]、B=[2,2,2,2,2]，SLO ≤4@p99）；不冒充真实测量。
