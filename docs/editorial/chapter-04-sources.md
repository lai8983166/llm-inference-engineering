# 第 04 章来源与编辑记录

## 使用规则

本章从第 03 章遗留的四条布局合同推导离散分段、固定块、块表与块池。正文中的技术陈述按四类管理：稳定分页与容量原理需要能够追溯到论文或一手文档；框架实现示例必须记录仓库、版本/commit 与核对日期，并只用于“实现示例”而不是“概念定义”；真实显存、查找与失败行为只能由对应软硬件上的测量支持；确定性教学模型假设只用整数逻辑单位，不以引用把假设包装成事实。

## 稳定分页与容量原理

| 待支持主张 | 一手来源 | 可以支持什么 | 不能推出什么 |
| --- | --- | --- | --- |
| 把每个序列的 KV cache 划分为定长 KV 块，每块容纳固定数量 token 的 key/value | [Efficient Memory Management for LLM Serving with PagedAttention](https://arxiv.org/abs/2309.06180)，Kwon 等，SOSP 2023，2026-08-26/27 核对（正文 3.1 节） | 定长块是已发表服务系统采用的布局；块内浪费被限制在每个序列的最后一个块（论文实验中合计不足 4%） | 不能推出本章教学池的任何数字，也不能推出某个真实服务的实际浪费比例 |
| 块表维护每个请求逻辑块到物理块的映射，每个表项记录对应的物理块 | 同上（3.1 节） | 块表是真实存在的显式映射数据结构；逻辑连续与物理非连续可以并存 | 不规定真实块表的数据类型、索引方式或并发协议；那些是实现事实 |
| 该设计“受操作系统经典虚拟内存与分页技术启发”，内存管理思想类比虚拟内存 | 同上（摘要与 3.1 节） | 分页思想的传承关系；固定粒度分配属于操作系统成熟原理 | 不把操作系统页表语义（缺页、权限、TLB）搬进本章；LLM 块池没有这些机制 |
| 等长分配使“任何空位可服务任何增长”的推导 | 本章第 2 节的手算表（确定性教学模型自身推导） | 变长分段的空位匹配失败、内部浪费封顶于每请求块数减一，均可手算复核 | 这是教学推导，不是引用事实；真实收益必须实测 |

## 必须实测的判断

以下问题在本章只能提出观察需求，不能由教学块池或逻辑步给出结论：

- 真实硬件上块表间接寻址对 attention kernel 耗时、带宽与寄存器压力的影响，以及与连续布局的同条件对照。
- 特定工作负载与块大小下的真实显存浪费、表元数据占用与吞吐变化。
- 真实 block allocator 的并发分配、释放与同步行为，以及 OOM 或准入失败的实际表现。
- 真实框架的 block size 默认值在具体模型与服务上的适用性；不应把教学计数当作选型依据。

真实结论必须沿用第 00 章的测量合同：固定请求集合与生成工作量，记录观察者和完成事件，保留原始事件、失败与环境信息，再限定结论适用范围。

## 确定性教学模型假设

任务组 1 的块池领域模型只用于形成可复核的因果轨迹：

- 模型与请求完全延续第 03 章：128 bytes/token、`R-long`/`R-short`/`R-late`（完成态 10/3/6 token unit）与 24-unit 物理池。
- 块池把物理池划为 6 块 × 4 token unit（每块 512 bytes）；完成态恰好 3/1/2 块，内部浪费 2/1/2 unit。
- 块编号、表项与逻辑步是整数教学单位，不对应 CUDA 地址、真实分配粒度、毫秒或 GPU cycle。
- 连续基线直接复用第 03 章 `buildKvTrace('on-demand-growth')`；块池轨迹使用同一步内顺序（到达准入 → decode 追加 → 步末统一完成裁决），保证两种布局可比。
- 块池事件不含搬迁类事件：这不是省略，而是该布局下“被迫搬迁”不再存在的直接结果；取消与完成只在读取结束后整块归还自己的块。
- 字段名、辅助文本与测试禁止出现 `ms`、`GB/s`、`utilization`，不得把块编号声称为真实显存块地址。
